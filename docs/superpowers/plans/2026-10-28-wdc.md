# WDC Desktop Ticker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Run a quiet WDC ticker with an extended-hours hover chart.
**Architecture:** A WPF process reads atomic JSON snapshots from a supervised local Python quote-only bridge. Quote normalization is independent of UI.
**Tech Stack:** .NET 9, WPF, Python 3.12, moomoo-api.
**Spec:** ../specs/2026-10-28-wdc-design.md

## Global Constraints
- Never present sample data as live. No trading APIs. No credentials stored.
- OpenD loopback only; settings and dependencies in the project.
- No alerts, focus stealing, or automatic startup registration.

## Review Focus
- Disconnection preserves last-known chart but explicitly marks it stale.
- Missing/zero extended-hours prices never replace valid prices or invent a change.
- Empty, flat, malformed and one-point charts remain safe.
- Market dates and source time use US Eastern time, including DST.
- Moving between ticker and chart must not immediately collapse the chart.
