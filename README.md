# 桌面股票行情条

双击桌面的 **股票行情条** 快捷方式即可启动；如果程序已在运行，会恢复显示现有窗口。也可使用项目内的 **启动行情条.cmd**。行情条显示在底部任务栏天气右侧，只显示代码、价格、涨跌幅和交易时段。

## 搜索和换股

1. **点击行情条左侧的股票代码 / 搜索符号**，打开搜索栏；也可右键选择“搜索 / 换股票”。
2. 输入股票代码或公司名称，例如 `NVDA`、`TSLA`、`英伟达`。
3. 选择结果，按回车、双击结果或点击“切换”。行情条保持显示你选择的股票，不自动轮播。

搜索不限于固定列表，支持公开行情源能识别的股票和部分其他标的。moomoo 导出的 122 个自选只作为本机搜索建议，因此可以搜索熟悉的中文名称。搜索框还会查询 Yahoo Finance 的在线搜索，且记住最近查看的股票及最后选择。

自选建议是本次从“全部”列表导入的快照，不会自动修改或持续同步 moomoo 的自选账户。moomoo 可以关闭，不影响行情条。

## 行情和市场

使用 Yahoo Finance、CNBC、Robinhood 的公开网页行情，无需登录或 OpenD。只请求当前选择的股票，不会同时轮询 122 个自选。切换期间先显示横线和连接状态，不把上一只的价格放到新代码下。

**行情分两条路**：Yahoo 的 WebSocket 推送是主路，成交一发生就到达（约 1 秒内），界面立即重绘；HTTP 作为兜底，在没有推送时约每 3 秒拉取一次，有推送时降为约每 10 秒心跳。推送永远只改价格和涨跌幅，**交易时段、币种这些元数据只认 HTTP**，所以推送不可能编造出一个时段。

- 美股显示盘前、盘中、盘后、夜盘或休市；真实夜盘报价不可用时显示“夜盘·暂无”。
- 盘前/盘中涨跌幅对比昨收，盘后/夜盘对比常规收盘价；休市显示常规收盘及当日涨跌幅。
- 韩股、A股等按公开源交易区间显示状态和币种；比特币显示“全天”。数据时间提示统一为美东时间 ET。
- ^TNX 为美国10年国债收益率参考。CL=F 为 Yahoo 当前近月 WTI 合约，换月时可能与 moomoo 主连不同。
- 黄金/白银现货 CFD 暂无对应的公开报价，保留搜索建议并明确显示不支持，不用期货价格冒充。
- 公开网页接口可能延迟、限流或改变；推送不等于交易所直连，不保证零延迟。连接失败时会降低请求频率。网络断线会标记旧报价；鼠标停留可查看来源和时间。
- **推送不是所有标的都有**。Yahoo 对很多非美股、小盘和指数不推送，实测 20 个自选里只有 6 个能推（可用 `bridge/probe_stream.py` 自己测）。没推送的标的仍走 HTTP 轮询，显示和行为与之前一致。
- 推送静默中断时，最后一次成功推送超过 10 秒后会自动回到 3 秒轮询，不会把旧报价挂在那里。

## 桌面操作

- 拖动价格区域调整位置；右键可锁定、调整透明度、恢复到天气右侧或退出。
- **Ctrl+Alt+W** 隐藏/显示；也可双击系统托盘图标。
- 没有走势图，不注册开机启动。
- `runtime/` 保存位置、最近查看、选择和行情快照；`watchlist.json` 仅存自选搜索建议，不保存账户密码。

本机已有环境。换电脑需要 Python 3.12 和 .NET 9 Desktop Runtime，再运行“安装依赖.cmd”；保留整个文件夹。
